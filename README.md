# Wallsite

Небольшой веб-сайт для публикации постов, созданный на Django в процессе изучения backend-разработки.

Проект начинался как учебный, но постепенно развивается в полноценное Django-приложение: сейчас в нём есть регистрация и авторизация пользователей, профили, публикация постов, лайки, загрузка изображений и работа с PostgreSQL.

## Демо

**Сайт:** [wallsite.ru]

Проект развёрнут на Beget и доступен через интернет.

## Возможности

### Пользователи

* регистрация;
* вход и выход из аккаунта;
* авторизация по email;
* профиль пользователя;
* изменение данных профиля;
* загрузка фотографии профиля;
* смена пароля;
* восстановление пароля через email.

### Посты

* создание постов;
* заголовок и текст поста;
* загрузка изображения;
* указание автора;
* возможность публиковать пост анонимно;
* просмотр отдельного поста;
* редактирование профиля;
* пагинация страниц с постами.

### Лайки

* авторизованный пользователь может поставить лайк посту;
* повторное нажатие убирает лайк;
* количество лайков отображается у поста.

## Модель данных

Основная модель приложения — `Wall`.

Пост содержит:

* заголовок;
* текст;
* slug;
* изображение;
* дату создания;
* дату изменения;
* автора;
* список пользователей, поставивших лайк;
* настройку анонимной публикации.

Для пользователя используется собственная модель на основе Django `AbstractUser`.

## Оптимизация запросов

При получении списка постов используются:

```python
Wall.objects.select_related('author').prefetch_related('likes')
```

Это позволяет избежать лишних запросов к базе данных при отображении списка постов.

## Запуск проекта

### 1. Клонирование

```bash
git clone <repository-url>
cd senmart28-django-educational-project-1-wallsite
```

### 2. Создание `.env`

Создайте файл `.env` на основе:

```text
.env.example
```

и укажите необходимые значения для Django, PostgreSQL и отправки email.

### 3. Запуск через Docker Compose

```bash
docker compose up --build
```

После запуска приложение будет доступно через настроенный Nginx.
Важно! Nginx настраивал не смостоятельно, я не уверен в его корректности!

## Зачем создан этот проект

Wallsite — мой учебный проект для практики backend-разработки на Python и Django.

Основная цель проекта — не просто собрать готовое приложение, а разобраться в том, как Django работает изнутри: модели, ORM, запросы к базе данных, формы, CBV, авторизация, шаблоны, связи между моделями, Docker и деплой приложения.

Проект постепенно развивается вместе с моими знаниями.
